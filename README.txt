FocusX Privacy Policy site

BEFORE PUBLISHING
1. Open index.html and replace REPLACE-WITH-YOUR-SUPPORT-EMAIL with an email address you control.
2. Review the policy against the exact FocusX build you are publishing. Remove or revise anything that does not match its real behavior.

PUBLISH WITH GITHUB PAGES
1. Create a public GitHub repository, e.g. focusx-privacy.
2. Upload index.html to the repository root.
3. Open repository Settings > Pages.
4. Select Deploy from a branch, choose branch main and folder /(root), then Save.
5. Wait for publishing. The URL will look like https://YOUR-USERNAME.github.io/focusx-privacy/
6. Open it in an incognito/private browser window and verify it loads without signing in.
7. Paste the public URL into the Privacy Policy URL field in the Indus Appstore console.

This ZIP does not itself publish a live URL. You must publish it using a hosting provider.
